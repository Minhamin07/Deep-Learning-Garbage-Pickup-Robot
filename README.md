
# 🤖 Deep Learning-Based Autonomous Garbage Pickup Robot with IoT-Based Mobile Monitoring

## 📌 About the Project

A collaborative group project focused on developing an autonomous garbage pickup robot using deep learning techniques for waste detection and IoT technology for mobile monitoring.

The project aims to reduce manual waste collection efforts through intelligent detection and automated garbage pickup.

## ✨ Key Features

- Deep Learning-Based Waste Detection
- Autonomous Garbage Pickup
- IoT-Based Mobile Monitoring
- Intelligent Object Detection
- Automated Waste Collection

## 🛠️ Technologies Used

- Python
- Deep Learning
- Computer Vision
- IoT
- Robotics

## 🎯 Project Objective

To develop an intelligent robotic solution for automated garbage detection and collection while enabling remote monitoring through IoT technology.

## 👥 Project Type

Academic Group Project
